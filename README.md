# Итоговое домашнее задание по JavaScript

## Что реализовано

- Оружие: `Weapon`, `Arm`, `Bow`, `Sword`, `Knife`, `Staff`, `LongBow`, `Axe`, `StormStaff`.
- Персонажи: `Player`, `Warrior`, `Archer`, `Mage`, `Dwarf`, `Crossbowman`, `Demiurge`.
- Механика боя: перемещение, выбор противника, атаки, блокирование, уклонение, износ и смена оружия.
- Поединки между несколькими персонажами с выводом действий и определением победителя.
- Тесты на Jest, включая проверку покрытия кода.

## Запуск

```bash
npm install
npm start
```

Команда `npm start` запускает пример с шестью персонажами из `index.js`.

## Тестирование

```bash
npm test
npm run test:coverage
```

## Файлы

- `weapon.js` — классы оружия.
- `player.js` — классы персонажей и методы боя.
- `game.js` — функция `play(players)`.
- `index.js` — пример запуска.
- `__tests__/` — автоматические тесты.
